STEP-BY-STEP EXPLANATION (3 minutes):
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

STEP 1: Show the Overall Layout (15 seconds)
───────────────────────────────────────────────────────────────────────────

Point at the PNG and say:
"This image shows a reconstruction comparison. It has 2 rows and 4 columns.

Top row (Row 1): Linear amplitude - raw signal strength
Bottom row (Row 2): B-mode dB scale - clinical ultrasound format

Columns show different reconstruction methods."

                        What to point at
                        ↓
    ┌────────────────────────────────────────┐
    │ ROW 1 (Linear Amplitude)                │ ← Point here
    ├────────────────────────────────────────┤
    │ ROW 2 (B-mode dB scale)                 │ ← Point here
    └────────────────────────────────────────┘
     ↑                                         ↑
     Point at columns                   Point at columns

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

STEP 2: Explain Column 1 - Ground Truth (30 seconds)
───────────────────────────────────────────────────────────────────────────

Point to the leftmost column and say:
"Column 1 is the ground truth. We KNOW where the scatterers are because
this is synthetic data. We created 2-6 point reflectors at specific locations.

You can see the bright dots (scatterers) on a black background. This is 
the 'target' we're trying to reconstruct with the other methods."

                What to point at
                ↓
    ┌──────────┬─────────┬──────────┬──────────┐
    │  GT ◄────│   DAS   │  FISTA   │  ABLE    │
    │ (WHITE   │         │          │          │
    │  DOTS)   │         │          │          │
    └──────────┴─────────┴──────────┴──────────┘

Say: "See the sharp white dots? That's what we're trying to match."

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

STEP 3: Explain Column 2 - DAS Baseline (30 seconds)
───────────────────────────────────────────────────────────────────────────

Point to column 2 and say:
"Column 2 is DAS - the Delay-and-Sum baseline. It's a simple beamformer
that treats all channels equally. It weights every channel the same.

Notice the dots are BLURRY. They're wider and less defined than the 
ground truth. This is because uniform weighting doesn't adapt to signal
quality - noisy channels pull down the reconstruction."

                What to point at
                ↓
    ┌──────────┬─────────────┬──────────┬──────────┐
    │   GT     │  DAS ◄──────│  FISTA   │  ABLE    │
    │          │  (BLURRY    │          │          │
    │          │   DOTS)     │          │          │
    └──────────┴─────────────┴──────────┴──────────┘

Say: "Compare column 1 (sharp) to column 2 (blurry). That's the problem
DAS has."

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

STEP 4: Explain Column 4 - ABLE (Our Method!) (45 seconds)
───────────────────────────────────────────────────────────────────────────

Point to column 4 (rightmost) and say:
"Column 4 is OUR METHOD - ABLE. This uses an MLP to learn ADAPTIVE weights.

The network learns: 'For this pixel, which channels should I trust?'
- High SNR channels → weight ≈ 1.0 (trust them)
- Low SNR channels → weight ≈ 0.0 (ignore them)

Look at the result: The dots are SHARP, like the ground truth.
Much better than DAS!"

                What to point at
                ↓
    ┌──────────┬─────────┬──────────┬──────────────┐
    │   GT     │   DAS   │  FISTA   │  ABLE ◄──────│
    │ (sharp)  │(blurry) │          │ (SHARP!)     │
    │          │         │          │              │
    └──────────┴─────────┴──────────┴──────────────┘

Compare visually:
"Look: Ground truth (left) vs ABLE (right). Much more similar!
Compare: DAS (2nd from left) vs ABLE (right). ABLE is sharper!"

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

STEP 5: Show the Numbers (30 seconds)
───────────────────────────────────────────────────────────────────────────

Open: demo_output/comparison_results.txt (or point to it)

Point to MAE values and say:
"Here are the error metrics (Mean Absolute Error):

DAS MAE:   17,500
ABLE MAE:   1,260

That means ABLE is 92.8% better than DAS!

Lower error = closer to ground truth."

Show calculation:
"(17,500 - 1,260) / 17,500 = 92.8% improvement"

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

STEP 6: Explain Row 2 (B-mode) (30 seconds)
───────────────────────────────────────────────────────────────────────────

Point to the bottom row and say:
"The bottom row is B-mode - that's what radiologists see in the clinic.
It's dB-compressed, ranging from -60 dB (black, weak) to 0 dB (white, strong).

You can see ABLE (right) has higher contrast than DAS (2nd from left).
The white dots stand out more clearly against the black background.

This shows ABLE works better in clinical reality, not just mathematically."

Compare visually in bottom row:
"DAS bottom = lower contrast
ABLE bottom = higher contrast (better for doctors)"

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

SUMMARY (What to say at the end) (30 seconds)
───────────────────────────────────────────────────────────────────────────

"To summarize:

Column 1 (Ground Truth): This is what we know is correct.

Column 2 (DAS): Baseline method with uniform weights. Blurry reconstruction.
MAE: 17,500

Column 4 (ABLE): Our learned method with adaptive weights. Sharp reconstruction.
MAE: 1,260

Visual improvement: Clear! ABLE is sharper, cleaner.
Numerical proof: 92.8% better!

The neural network learned which channels to trust per pixel, resulting
in significantly better reconstruction."

WHAT IF PROFESSOR ASKS QUESTIONS?
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Q: "Why is DAS blurry?"
A: "DAS treats all channels equally. Some channels have high SNR (good),
   some have low SNR (noisy). Uniform weighting compromises both.
   ABLE learns to weight them differently per pixel."

Q: "How does it learn the weights?"
A: "The MLP network takes 4096 aligned channel values as input and predicts
   4096 weights. We minimize a loss function (80% reconstruction + 20% unity)
   over 5000 training steps."

Q: "Why are there 3 methods, not just 2?"
A: "FISTA is a standard iterative sparse reconstruction method we compared
   against. But it's not our focus - we mainly show DAS vs ABLE."

Q: "Can you show me case 02 or case 03?"
A: "Sure! [Open the other PNG]. Same pattern - ABLE is consistently
   sharper than DAS across different scatterer patterns."
